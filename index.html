Mức nén

    Word, PowerPoint, Excel, LibreOffice, EPUB: nén lại ảnh bên trong file, chữ và định dạng giữ nguyên. Ảnh: thu nhỏ và nén lại. PDF: nén bằng Ghostscript, chữ vẫn chọn được. Lần đầu nén PDF cần tải thư viện khoảng 15 MB.

    Công cụ hoạt động như thế nào?
    1. Chọn file: kéo thả hoặc bấm để chọn file PDF, Word, PowerPoint, Excel (kể cả bản có macro .docm .pptm .xlsm), LibreOffice (.odt .ods .odp), EPUB hoặc ảnh JPG/PNG/WEBP. Chọn được nhiều file cùng lúc.
    2. Chọn mức nén: "Nén mạnh" cho file nhỏ nhất, "Khuyên dùng" cân bằng, "Chất lượng cao" giữ ảnh nét hơn.
    3. Tải về: tải từng file hoặc bấm "Tải tất cả (ZIP)".

    PDF: dùng Ghostscript (bản WebAssembly chạy trong trình duyệt) để nén lại ảnh và tối ưu file. Chữ vẫn giữ nguyên, vẫn chọn và tìm kiếm được. Lần đầu cần tải thư viện khoảng 15 MB.

    Word, PowerPoint, Excel: các file này thực chất là file ZIP. Công cụ mở ra, thu nhỏ và nén lại ảnh bên trong (ảnh không trong suốt đổi sang JPG), rồi đóng gói lại. Chữ, bảng, định dạng giữ nguyên.

    LibreOffice, EPUB: cũng là file ZIP, ảnh bên trong được thu nhỏ và nén lại nhưng giữ nguyên định dạng ảnh để file mở bình thường.

    Ảnh JPG/PNG/WEBP: thu nhỏ theo mức nén rồi nén lại. Ảnh PNG không có nền trong suốt sẽ đổi sang JPG cho nhẹ.

    Mọi thứ chạy trên máy bạn, file không được tải lên máy chủ nào. Nếu file sau khi nén không nhỏ hơn, công cụ giữ nguyên file gốc. File gần như không có ảnh sẽ giảm rất ít.

    How does it work?
    1. Add files: drag and drop or click to choose PDF, Word, PowerPoint, Excel (including macro files .docm .pptm .xlsm), LibreOffice (.odt .ods .odp), EPUB or JPG/PNG/WEBP images. Several at once is fine.
    2. Pick a level: "Strong" for the smallest files, "Recommended" for balance, "High quality" keeps images sharper.
    3. Download: one by one, or all at once as a ZIP.

    PDF: compressed with Ghostscript (a WebAssembly build running in your browser), which re-encodes images and optimizes the file. Text stays selectable and searchable. The first run downloads about 15 MB.

    Word, PowerPoint, Excel: these files are ZIP archives. The tool opens them, downsizes and re-compresses the images inside (opaque images become JPG), then packs them back. Text, tables and formatting stay the same.

    LibreOffice, EPUB: also ZIP files; images inside are downsized and re-compressed but keep their format so the file still opens normally.

    JPG/PNG/WEBP images: resized for the chosen level and re-compressed. PNGs without transparency become JPG to save space.

    Everything runs on your device; nothing is uploaded. If a result is not smaller, the original is kept. Files with few images will shrink only a little.
